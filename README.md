# Money Manager

Live Demo: https://moneyrishi.ccbp.tech


## Project Overview

Money Manager is a responsive web application that helps users track their income and expenses. Users can add transactions, view balance updates instantly, and delete transactions when required.

This project demonstrates React state management, event handling, component structuring, and responsive UI design.


## Features

- Add income and expense transactions
- Real-time balance calculation
- Transaction history tracking
- Delete transactions
- Responsive design for mobile, tablet, and desktop
- User-friendly interface


## Technologies Used

- React.js
- JavaScript (ES6)
- CSS3
- UUID Package
- HTML5

## Functionalities

### Add Transaction
Users can enter:
- Title
- Amount
- Transaction Type (Income / Expenses)


### Balance Calculation

Balance = Income - Expenses


### Delete Transaction
Users can remove transactions and the balance updates automatically.

## Installation and Setup

Clone the repository:

git clone https://github.com/Rishitha73/Money-Manager.git

Navigate to project folder:

cd Money-Manager

Install dependencies:

npm install

Run project:

npm start
